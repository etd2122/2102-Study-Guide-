Pandas is a Python library for working with labeled data. Its two main data structures are the Series, which stores a one-dimensional sequence of values with labels, and the DataFrame, which stores a table with row and column labels. The labels identify observations and variables, and they also affect how selection and arithmetic work.

1. Series and DataFrames

The conventional abbreviations are pd for pandas and np for NumPy. The statement import pandas as pd makes pandas available through the name pd. NumPy supplies np.nan, which represents a missing numerical value in the examples below.

import numpy as np
import pandas as pd

A Series: values with an index

A Series associates each value with an index label. In the following Series, the values are quiz scores and the labels are student IDs. The optional name describes the Series; it is separate from its index.

scores = pd.Series([60, 82, 75], index=[101, 104, 107], name="quiz_1")
print(scores)
print(scores.index.tolist())
print(scores.loc[107])

Output:

101    60
104    82
107    75
Name: quiz_1, dtype: int64
[101, 104, 107]
75

The left-hand column contains the labels 101, 104, and 107. The right-hand column contains the scores 60, 82, and 75. The expression scores.loc[107] selects the score whose label is 107, so its result is 75. dtype: int64 describes the numerical type used for the stored scores.

Arithmetic with a scalar acts on every value and preserves the labels. Similarly, a comparison produces a Boolean Series with the same index.

print(scores + 5)
print(scores >= 75)

Output:

101    65
104    87
107    80
Name: quiz_1, dtype: int64
101    False
104     True
107     True
Name: quiz_1, dtype: bool

Adding 5 increases each score by 5. The comparison tests each score separately, producing False, True, and True. These are vectorized operations: one expression operates on the whole Series.

A DataFrame: labeled rows and columns

A DataFrame is a two-dimensional table. Each column is a Series, and different columns can store different types of values. A dictionary of equal-length lists is one way to create a DataFrame: dictionary keys become column names, and the entries in the lists become column values.

Each row below represents a fictional student. The columns contain a name, section, study hours, and two quiz scores out of 100. The row index contains student IDs. Gia’s study hours and Cam’s second quiz score are missing.

df = pd.DataFrame({
    "student": ["Ari", "Bo", "Cam", "Dev", "Eli", "Fay", "Gia", "Han"],
    "section": ["AM", "PM", "AM", "PM", "AM", "PM", "AM", "PM"],
    "hours": [2.0, 4.5, 3.0, 5.0, 1.5, 4.0, np.nan, 2.5],
    "quiz_1": [60, 82, 75, 90, 55, 88, 70, 68],
    "quiz_2": [68, 85, np.nan, 94, 64, 91, 78, 72]
}, index=[101, 104, 107, 110, 113, 116, 119, 122])
df.index.name = "student_id"
print(df)

Output:

           student section  hours  quiz_1  quiz_2
student_id                                       
101            Ari      AM    2.0      60    68.0
104             Bo      PM    4.5      82    85.0
107            Cam      AM    3.0      75     NaN
110            Dev      PM    5.0      90    94.0
113            Eli      AM    1.5      55    64.0
116            Fay      PM    4.0      88    91.0
119            Gia      AM    NaN      70    78.0
122            Han      PM    2.5      68    72.0

The index is displayed on the left, with the name student_id. It is not one of the five data columns. The label 107 identifies Cam; Cam’s current row position is 2 because positions begin at 0.

The attributes shape, columns, and index describe the structure of the table. The method head(n) returns the first n rows.

print(df.shape)
print(df.columns.tolist())
print(df.index.tolist())
print(df.head(2))

Output:

(8, 5)
['student', 'section', 'hours', 'quiz_1', 'quiz_2']
[101, 104, 107, 110, 113, 116, 119, 122]
           student section  hours  quiz_1  quiz_2
student_id                                       
101            Ari      AM    2.0      60    68.0
104             Bo      PM    4.5      82    85.0

The shape (8, 5) means eight rows and five columns. The two lists report the column labels and row labels in their current order.

2. Selecting rows and columns

One column or a table of columns

The number of brackets affects the result. A single column label, df["quiz_1"], selects a Series. A list of labels, df[["quiz_1"]], selects a DataFrame, even when the list contains only one column. A list with several labels selects those columns in the specified order.

one_series = df["quiz_1"]
one_column = df[["quiz_1"]]

print(type(one_series).__name__, one_series.shape)
print(type(one_column).__name__, one_column.shape)
print(df[["student", "quiz_1"]].head(3))

Output:

Series (8,)
DataFrame (8, 1)
           student  quiz_1
student_id                
101            Ari      60
104             Bo      82
107            Cam      75

The Series has shape (8,), with one axis. The one-column DataFrame has shape (8, 1), with separate row and column axes. The inner brackets in [["quiz_1"]] create a Python list; the outer brackets perform the column selection.

Labels with .loc, positions with .iloc

Both selectors accept a row selection and a column selection separated by a comma. .loc uses labels, while .iloc uses integer positions. An integer passed to .loc is still a label.

Selection Meaning
df.loc[107, "student"] Student name at row label 107
df.iloc[2, 0] Value at row position 2 and column position 0
df.loc[[101, 107], ["student", "quiz_1"]] Specified row and column labels
df.iloc[[0, 2], [0, 3]] Specified row and column positions
df.loc[:, "quiz_1"] Every row of the named column

In the current table, the first two expressions below refer to the same value. Negative positions count from the end.

print(df.loc[107, "student"])
print(df.iloc[2, 0])
print(df.iloc[-1, 0])

Output:

Cam
Cam
Han

The results are Cam, Cam, and Han. The expression df.loc[0] would raise KeyError because there is no row labeled 0. By comparison, df.iloc[0] selects the first row. If the table is reordered, .loc[107] continues to identify Cam, while .iloc[2] refers to whichever row is now third.

Slicing

For a label slice whose endpoints are present, .loc includes both endpoints. A positional slice with .iloc follows ordinary Python slicing: it includes the start and excludes the stop.

print(df.loc[104:110, ["student", "quiz_1"]])
print(df.iloc[1:3, [0, 3]])

Output:

           student  quiz_1
student_id                
104             Bo      82
107            Cam      75
110            Dev      90
           student  quiz_1
student_id                
104             Bo      82
107            Cam      75

The label slice includes IDs 104, 107, and 110, so it returns three rows. The position slice includes positions 1 and 2, so it returns two rows. The label slice follows the current index order; it does not mean “all integer positions between 104 and 110.”

3. Filtering rows with Boolean conditions

A comparison applied to a column produces a Boolean Series. Such a Series can act as a mask: rows corresponding to True are retained and rows corresponding to False are removed. The mask below identifies students with at least three recorded study hours.

mask = df["hours"] >= 3
print(mask)
print(df.loc[mask, ["student", "hours"]])

Output:

student_id
101    False
104     True
107     True
110     True
113    False
116     True
119    False
122    False
Name: hours, dtype: bool
           student  hours
student_id               
104             Bo    4.5
107            Cam    3.0
110            Dev    5.0
116            Fay    4.0

Bo, Cam, Dev, and Fay satisfy the condition. Gia’s hours are represented by floating-point NaN; in this comparison, NaN >= 3 is False, so Gia’s row is not selected.

Several conditions can be combined using elementwise Boolean operators. Parentheses around each comparison make the intended order of operations explicit.

Operator Meaning Example
& Both conditions hold (df["hours"] >= 3) & (df["quiz_1"] >= 80)
| At least one condition holds (df["section"] == "AM") | (df["quiz_1"] >= 90)
~ Negate a Boolean condition ~(df["section"] == "AM")

Python’s and and or test the truth of whole objects; they do not combine these Series conditions element by element. Pandas masks use & and |.

mask = (df["hours"] >= 3) & (df["quiz_1"] >= 80)
print(df.loc[mask, ["student", "hours", "quiz_1"]])

Output:

           student  hours  quiz_1
student_id                       
104             Bo    4.5      82
110            Dev    5.0      90
116            Fay    4.0      88

Bo, Dev, and Fay meet both requirements. Cam meets the hours requirement but has a Quiz 1 score of 75, so Cam is excluded by the second condition. The result retains the original student ID labels.

The method isin() tests whether each value belongs to a specified collection. It returns a Boolean Series that can be used in the same way.

is_morning = df["section"].isin(["AM"])
print(df.loc[is_morning, ["student", "section"]])

Output:

           student section
student_id                
101            Ari      AM
107            Cam      AM
113            Eli      AM
119            Gia      AM

The selected students are Ari, Cam, Eli, and Gia. The list passed to isin() can contain several accepted values, which is useful when a column has more than two categories.

4. Calculating and assigning columns

Arithmetic between two columns operates on their corresponding labels. A new column can be created by assigning a Series to a new column name. Here, gain records the difference between the two quiz scores.

practice = df.copy()
practice["gain"] = practice["quiz_2"] - practice["quiz_1"]
print(practice[["student", "quiz_1", "quiz_2", "gain"]])

Output:

           student  quiz_1  quiz_2  gain
student_id                              
101            Ari      60    68.0   8.0
104             Bo      82    85.0   3.0
107            Cam      75     NaN   NaN
110            Dev      90    94.0   4.0
113            Eli      55    64.0   9.0
116            Fay      88    91.0   3.0
119            Gia      70    78.0   8.0
122            Han      68    72.0   4.0

Ari’s gain is 68 - 60 = 8, and Eli’s gain is 64 - 55 = 9. Cam’s gain is missing because one of the two required scores is missing. The expression calculates all gains without a loop.

The call df.copy() creates a separate table for these changes. By comparison, practice = df would make another name refer to the same DataFrame.

To change a column only for selected rows, .loc combines the row condition and column name in one assignment. The following example creates an adjusted score and adds two points for AM students.

practice["adjusted_quiz_1"] = practice["quiz_1"]
is_am = practice["section"] == "AM"
practice.loc[is_am, "adjusted_quiz_1"] = (
    practice.loc[is_am, "adjusted_quiz_1"] + 2
)
print(practice[["student", "section", "quiz_1", "adjusted_quiz_1"]])

Output:

           student section  quiz_1  adjusted_quiz_1
student_id                                         
101            Ari      AM      60               62
104             Bo      PM      82               82
107            Cam      AM      75               77
110            Dev      PM      90               90
113            Eli      AM      55               57
116            Fay      PM      88               88
119            Gia      AM      70               72
122            Han      PM      68               68

The AM scores increase by two and the PM scores retain their original values. The expression on the right computes the replacement values; the .loc expression on the left specifies the cells to update. The original df remains unchanged because the updates were made to practice, which was created with copy().

5. Reindexing, dropping, and label alignment

Reindexing and dropping

The method reindex() creates a result with specified labels in a specified order. Existing values are matched to those labels. A requested label absent from the original object introduces missing values.

reordered = df.reindex([122, 101, 125])
print(reordered[["student", "quiz_1"]])

Output:

           student  quiz_1
student_id                
122            Han    68.0
101            Ari    60.0
125            NaN     NaN

Han appears first because 122 is the first requested label. Ari appears second because the next label is 101. ID 125 was not in the original table, so that row contains missing values. Reindexing changes the selection and ordering of labels; it does not reinterpret labels as positions.

The method drop() removes labels. The columns argument identifies column labels to remove, while index identifies row labels. These calls return new DataFrames by default.

without_hours = df.drop(columns="hours")
without_han = df.drop(index=122)
print(without_hours.columns.tolist())
print(without_han.shape)
print(df.shape)

Output:

['student', 'section', 'quiz_1', 'quiz_2']
(7, 5)
(8, 5)

The first result has four columns, the second has seven rows, and the original table still has shape (8, 5).

Arithmetic matches labels

Pandas aligns Series by index label before performing arithmetic. The order in which the values were written does not determine their pairing. Consider a base-score Series and a bonus Series with a different order and a different set of labels.

base = df.loc[[101, 104, 107], "quiz_1"]
bonus = pd.Series([3, 5, 2], index=[107, 101, 125])
print(base)
print(bonus)
print(base + bonus)

Output:

student_id
101    60
104    82
107    75
Name: quiz_1, dtype: int64
107    3
101    5
125    2
dtype: int64
101    65.0
104     NaN
107    78.0
125     NaN
dtype: float64

ID 101 receives 60 + 5 = 65, while ID 107 receives 75 + 3 = 78. The result uses the union of the labels. ID 104 has no bonus entry and ID 125 has no base-score entry, so ordinary addition gives missing results for those two labels.

The method add() accepts fill_value, which supplies a value for a missing operand when the other operand is available.

print(base.add(bonus, fill_value=0))

Output:

101    65.0
104    82.0
107    78.0
125     2.0
dtype: float64

This operation produces 82 for ID 104 and 2 for ID 125. It treats the absent bonus for 104 as zero, but it also treats the absent base score for 125 as zero. That is a mathematical rule for this addition; it does not establish that student 125 actually had a base score of zero.

If the intended report contains exactly the students in base, the bonus can first be reindexed to that roster. Filling missing bonuses then means that a student without a bonus receives zero extra points.

roster_bonus = bonus.reindex(base.index)
print(roster_bonus)
print(base + roster_bonus.fillna(0))

Output:

student_id
101    5.0
104    NaN
107    3.0
dtype: float64
student_id
101    65.0
104    82.0
107    78.0
dtype: float64

The result contains only IDs 101, 104, and 107, with final scores 65, 82, and 78. ID 125 is excluded by the choice of roster. DataFrames also align labels in arithmetic, using both their row and column labels.

6. Missing values and descriptive summaries

Identifying missing values

The methods isna() and notna() identify missing and observed values. A missing value cannot be identified reliably with value == np.nan; the missing-value methods express the intended test. Summing a Boolean Series counts its True entries because they are treated as 1, while False entries are treated as 0.

print(df.loc[df["hours"].isna(), ["student", "hours"]])
print(df["quiz_2"].isna().sum())
print(df["quiz_2"].notna().sum())

Output:

           student  hours
student_id               
119            Gia    NaN
1
7

Gia has the missing hours entry. Quiz 2 has one missing score and seven observed scores. The method fillna(value) returns an object in which missing entries have been replaced by value, as in the bonus example. The choice of replacement changes the meaning of subsequent calculations; a missing quiz score does not automatically represent a score of zero.

Column summaries and row summaries

Summary methods reduce an axis. By default, methods such as mean() reduce the row axis, producing one result per column. Setting axis="columns" reduces the column axis, producing one result per row.

Argument Axis reduced Result for a table of quiz scores
axis="index" or axis=0 (default) Rows One mean for each quiz
axis="columns" or axis=1 Columns One mean for each student

The table of quiz scores is selected explicitly so that the numerical summaries do not include names or section labels.

quizzes = df[["quiz_1", "quiz_2"]]
print(quizzes.mean())
print(quizzes.mean(axis="columns"))

Output:

quiz_1    73.500000
quiz_2    78.857143
dtype: float64
student_id
101    64.0
104    83.5
107    75.0
110    92.0
113    59.5
116    89.5
119    74.0
122    70.0
dtype: float64

The Quiz 1 mean is 73.5 and uses all eight scores. The Quiz 2 mean is approximately 78.86 and uses seven scores. By default, mean() skips missing values. Cam’s row mean is therefore 75, calculated using the one available quiz score.

The argument skipna=False makes a mean missing when a required value is missing. For this two-column table, it expresses a rule that both quiz scores must be observed for a student’s mean to be reported.

print(quizzes.mean(axis="columns", skipna=False))
print(quizzes.count())

Output:

student_id
101    64.0
104    83.5
107     NaN
110    92.0
113    59.5
116    89.5
119    74.0
122    70.0
dtype: float64
quiz_1    8
quiz_2    7
dtype: int64

Cam’s mean is now missing. The other row means are unchanged. The method count() reports the number of observed values in each column, which makes the denominators of the column means explicit. Related summary methods include sum(), min(), max(), and std().

7. Sorting, ranking, and counting values

Sorting by values or by index

The method sort_values() orders rows by the values in one or more columns. The argument ascending=False requests descending order. The original index labels stay attached to their rows.

observed = df.loc[df["quiz_2"].notna(), ["student", "quiz_2"]]
top_three = observed.sort_values("quiz_2", ascending=False).head(3)
print(top_three)

Output:

           student  quiz_2
student_id                
110            Dev    94.0
116            Fay    91.0
104             Bo    85.0

The three highest observed Quiz 2 scores belong to Dev (94), Fay (91), and Bo (85). Their row labels remain 110, 116, and 104. Sorting rows does not reset the index.

By comparison, sort_index() orders an object by its labels. A multi-column sort uses the listed columns in order: the second column breaks ties in the first. For example, sort_values(["gain", "student"], ascending=[False, True]) orders by gain descending and then by name ascending.

Ranking and ties

Ranks describe relative position without changing the order of the Series. With ascending=False, the highest value receives rank 1. The default treatment of ties assigns the average of the tied ranks.

tied = pd.Series([88, 95, 88], index=["Ari", "Bo", "Cam"])
print(tied.rank(ascending=False))

Output:

Ari    2.5
Bo     1.0
Cam    2.5
dtype: float64

Bo receives rank 1. Ari and Cam occupy the next two places, so both receive (2 + 3) / 2 = 2.5. The displayed order is still Ari, Bo, Cam; ranking has not sorted the Series.

Unique values and frequencies

The method unique() returns distinct values in order of appearance. The method value_counts() returns a Series of frequencies, sorted by frequency in descending order by default. It excludes missing values unless dropna=False is supplied.

print(df["section"].unique())
print(df["section"].value_counts())

Output:

['AM' 'PM']
section
AM    4
PM    4
Name: count, dtype: int64

The distinct labels are AM and PM, and each occurs four times. The index of the frequency Series contains category labels; its values contain the counts. The isin() method introduced earlier provides the corresponding membership test for selecting categories.

8. Mapping values and applying functions

The method Series.map() applies a mapping or function to each value of a Series. A dictionary is useful for replacing short category labels with descriptive names.

section_names = df["section"].map({"AM": "Morning", "PM": "Afternoon"})
print(section_names)

Output:

student_id
101      Morning
104    Afternoon
107      Morning
110    Afternoon
113      Morning
116    Afternoon
119      Morning
122    Afternoon
Name: section, dtype: object

The values have changed, while the student ID index has been retained. With an ordinary dictionary, a value without a matching key maps to a missing value.

The method DataFrame.apply() passes each column, or each row, to a function. Its default is axis=0, which applies the function to each column. With axis="columns", the function receives one row at a time. The following function calculates the range of the available quiz scores.

def score_range(row):
    return row.max() - row.min()

ranges = quizzes.apply(score_range, axis="columns")
print(ranges)

Output:

student_id
101    8.0
104    3.0
107    0.0
110    4.0
113    9.0
116    3.0
119    8.0
122    4.0
dtype: float64

Ari’s range is 68 - 60 = 8. Cam has only one observed score, so the default missing-value behavior of max() and min() makes both equal to 75, producing a range of 0. That result describes the observed values; it does not mean the two quiz scores were equal.

Vectorized expressions such as df["quiz_2"] - df["quiz_1"] express simple column arithmetic directly. apply() is useful when a function needs to process a whole row or column.

9. Duplicate labels and correlation

An index can contain duplicate labels

Pandas indexes are not required to be unique. The attribute index.is_unique reports whether labels are repeated. A selection by a repeated label returns all matching entries.

marks = pd.Series([70, 80, 90], index=["lab", "lab", "exam"])
print(marks.index.is_unique)
print(marks.loc["lab"])

Output:

False
lab    70
lab    80
dtype: int64

The result is a two-entry Series because there are two entries labeled "lab". With a unique label, a scalar selection from a Series would return a single value. In the student table, the IDs are unique, so each row label identifies one student.

Correlation uses paired observations

The method Series.corr() computes Pearson correlation by default. It aligns the two Series by their labels and uses pairs for which both values are observed. Cam is excluded because Quiz 2 is missing.

complete = quizzes.notna().all(axis="columns")
print(complete.sum())
print(round(df["quiz_1"].corr(df["quiz_2"]), 4))

Output:

7
0.9922

There are seven complete pairs. The positive correlation describes the association between the two quiz scores in this fictional dataset. It does not establish a causal effect of study hours on quiz scores. The corresponding covariance can be computed with Series.cov(); a numerical DataFrame also provides corr() and cov() matrices.

10. Connections with R

A pandas DataFrame serves a similar tabular role to an R data frame, but the selection syntax and some defaults differ. In particular, Python positions begin at 0, and pandas makes a strong distinction between index labels and integer positions.

Operation R Python / pandas
Assign a value x <- 3 x = 3
Select a column as a vector or Series df$quiz_1 or df[["quiz_1"]] df["quiz_1"]
Select a one-column table df["quiz_1"] df[["quiz_1"]]
Select the first row by position df[1, ] df.iloc[0]
Test for missing values is.na(x) x.isna()
Mean ignoring missing values mean(x, na.rm=TRUE) x.mean()
Count category values table(x) x.value_counts()
Combine vector conditions (a) & (b) (a) & (b)

The first-row expressions select corresponding observations but have different default return types: R generally retains a one-row data frame in this case, while df.iloc[0] is a Series. In pandas, df.iloc[[0]] retains a one-row DataFrame.

Arithmetic on ordinary R numeric vectors follows position, including when they have names. Arithmetic on pandas Series aligns index labels. The missing-value defaults of a mean also differ: R’s mean(x) propagates NA by default, while pandas mean() skips missing values by default.

11. Worked example: a report of quiz improvements

The following report contains students with an observed second quiz score and an improvement of at least five points. It shows the student name, section, and gain, ordered by gain descending and then by name ascending. The calculation begins with the original table.

report = df.copy()
report["gain"] = report["quiz_2"] - report["quiz_1"]

keep = report["quiz_2"].notna() & (report["gain"] >= 5)
report = report.loc[keep, ["student", "section", "gain"]]
report = report.sort_values(
    ["gain", "student"], ascending=[False, True]
)
print(report)

Output:

           student section  gain
student_id                      
113            Eli      AM   9.0
101            Ari      AM   8.0
119            Gia      AM   8.0

The first assignment creates a separate table, and the next computes the gain for every student. The mask combines an observed-value test with a numerical threshold. The .loc selection keeps the rows that satisfy the mask and the three columns needed for the report.

Eli appears first with a gain of 9. Ari and Gia both have gains of 8, so their names determine their order. The labels 113, 101, and 119 continue to identify the same students after filtering and sorting. The report combines column arithmetic, Boolean selection, and sorting while preserving the labels that connect each result to its observation.

Exercise 2: matching bonuses to student IDs

The following base scores and bonuses refer to students by ID. The bonus Series has a different order, omits one student, and includes one additional student.

exercise_scores = pd.Series([72, 84, 66], index=[201, 204, 207])
exercise_bonus = pd.Series([4, 3, 2], index=[207, 201, 210])
  1. Predict the index labels and values of exercise_scores + exercise_bonus, including any missing results.
  2. Calculate adjusted scores for exactly the students in exercise_scores. An absent bonus should count as zero. Preserve the original student order.
  3. Explain why exercise_scores.add(exercise_bonus, fill_value=0) does not, by itself, produce the requested roster.
Solution 
print(exercise_scores + exercise_bonus)

aligned_bonus = exercise_bonus.reindex(exercise_scores.index)
adjusted_scores = exercise_scores + aligned_bonus.fillna(0)
print(adjusted_scores)

print(exercise_scores.add(exercise_bonus, fill_value=0))

Ordinary addition pairs matching IDs: student 201 receives 72 + 3 = 75, and student 207 receives 66 + 4 = 70. Student 204 has no bonus entry, while student 210 has no base score, so their ordinary sums are missing.

Reindexing the bonuses to the base-score index retains only 201, 204, and 207, in that order. Filling the absent bonus with zero gives adjusted scores 75, 84, and 70. In contrast, add(..., fill_value=0) also retains student 210 and gives that student a value of 2, so its roster is larger than the requested one.
